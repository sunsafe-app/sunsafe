SunSafe Architecture

Telegram bot for personal UV exposure tracking. The bot runs 24/7 in a Hugging Face Space, data lives in Supabase, and two cron jobs keep sessions and the Space alive.

Chat flow Web flow Scheduled jobs

Chat flow

  1. The user sends a command, a question, a photo or their location in Telegram.
  2. app.py keeps a polling thread on getUpdates and hands every update to bot_commands.py.
  3. Known commands run directly. Free text goes through the gatekeeper and rate limit; photos go to the skin classifiers.
  4. Valid questions enter the agent loop, which calls Gemini and uses the MCP weather tools against Open-Meteo.
  5. Readings, sessions and alerts are written to Postgres, and the reply goes back through the Bot API.

Web flow

  1. /dashboard sends a 24-hour magic link; /offline_session sends a Mini App button.
  2. The static pages call the Edge Functions with the token over HTTPS.
  3. Edge Functions recompute UV and exposure score server-side (Open-Meteo, Nominatim) before touching Postgres.

Scheduled jobs

  1. Every 5 minutes the Cloudflare Worker closes sessions that passed local sunset, writes the score and messages the user.
  2. Every 10 minutes GitHub Actions pings the Space URL so the free tier never sleeps.
